# تطبيق صحتي | Sehhaty
**تطوير: MTA TECHNOLOGIES**
**اسم الحزمة:** `com.mtaapps.sehhaty`

مشروع Android أصلي متكامل بعد التحديث الشامل للهوية البصرية والتصميم (Professional Redesign) بمستوى التطبيقات الصحية العالمية.

---

## 🌟 الميزات والتحديثات البصرية
1. **الأيقونة الرسمية الأصلية لـ صحتي:**
   - متضمنة بكافة كثافات أندرويد (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi).
   - أيقونة تكيفية Adaptive Icon (Foreground & Background) مع الحفاظ على منطقة الأمان لمنع قص الشعار.
   - نسخ دائرية ومربعة متوافقة مع كافة أجهزة أندرويد.
   - متضمنة في شاشة البداية، النشاط الرئيسي، وبطاقة حول التطبيق.

2. **نظام تصميم طبي متكامل (Design System):**
   - لوحة ألوان مستوحاة مباشرة من شعار صحتي (Brand Teal #088395, Brand Navy #0A4D68, Brand Cyan #05BFDB, Brand Mint #00FFCA, Brand Amber #F59E0B).
   - واجهات Jetpack Compose Material 3 مع دعم أصلي كامل للغة العربية RTL والإنجليزية.
   - بطاقات إحصائية للملخص اليومي ومؤشرات تقدم دائرية.
   - معالج إضافة دواء تفاعلي من 5 خطوات (5-Step Wizard).

3. **التذكيرات والتنبيهات المستقلة 100% دون إنترنت:**
   - تعمل بنظام Android AlarmManager بدقة عالية.
   - تكرار الرنين كل دقيقتين حتى تأكيد الجرعة.
   - أزرار تفاعلية داخل الإشعار (تم التناول ✓ / تأجيل 10 دقائق ⏰).
   - استعادة التنبيهات تلقائياً عند إعادة تشغيل الهاتف (BootReceiver).

4. **محرك بحث دوائي وتعرف بالذكاء الاصطناعي:**
   - دليل صيدلي مدمج في Room يعمل بدون إنترنت مع بطاقة 12 معياراً معتمداً.
   - تصوير العلبة والنشرة واستخراج النصوص ومطابقتها.

5. **مشرف الأسرة للمتابعة الطارئة:**
   - تسجيل الأقارب وتحديد مهلة الانتظار قبل التنبيه.
   - صياغة مسؤولة طبياً «لم يتم تأكيد الجرعة» وتكامل واتساب.

6. **GitHub Actions CI/CD:**
   - ملف جاهز في `.github/workflows/android-build.yml` لاستخراج Debug و Release APK فور الرفع.
